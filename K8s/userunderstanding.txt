Kubernetes object view

For User, we'll create:

User
 │
 ├── Deployment
 │      └── user Pod
 │             │
 │             ├──→ mongodb:27017
 │             │
 │             └──→ redis:6379
 │
 └── Service
        └── user:8080
What you'll learn from User

This component is particularly useful because it has two dependencies:

User Pod
  │
  ├── Service DNS → mongodb
  │
  └── Service DNS → redis

So compared with Catalogue:

Catalogue → MongoDB

User gives you:

User → MongoDB
     → Redis

This is a good opportunity to understand one microservice communicating with multiple Kubernetes Services.
